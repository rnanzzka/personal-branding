Tentang Saya

Halo! Saya Zabrena.

Saya siswa yang mengikuti ekstrakurikuler informatika karena merasa cukup tertarik untuk mengenal dunia teknologi lebih jauh. Juga,ingin mencoba hal baru yang salah satunya di bidang teknologi. Sejujurnya, saya masih belum benar-benar memahami materi seperti HTML, CSS, maupun pemrograman karena ini pertama kalinya. Banyak hal yang masih terasa baru buat saya.

Tapi, saya percaya bahwa setiap proses belajar pasti membutuhkan waktu. Saya suka untuk terus belajar, bertanya, dan memahami konsepnya sedikit demi sedikit. Bagi saya, kemajuan kecil tetap merupakan sebuah kemajuan.

Hal yang Saya Pelajari Sejauh Ini

  • Mengenal HTML sebagai struktur dasar sebuah website.
  • Memahami bahwa CSS digunakan untuk mengatur tampilan halaman web.
  • Mulai mengenal pentingnya logika dalam pemrograman.
  • Belajar bahwa teknologi tidak hanya tentang coding, tetapi juga tentang proses berpikir dan menyelesaikan masalah.

Sedang Saya Pelajari

  • Dasar-dasar pengembangan website.
  • Cara berpikir logis dalam menyelesaikan masalah.
  • Membangun kebiasaan untuk terus belajar dan mencoba hal baru.

Tujuan Saya

Saya ingin memahami dasar-dasar pengembangan website dengan lebih baik, mampu membuat proyek sederhana secara mandiri, juga terus mengembangkan kemampuan di bidang teknologi.
